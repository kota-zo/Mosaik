# Mosaik

All your messages in one Android app: WhatsApp, Instagram, Telegram, Discord, Snapchat and your
phone's SMS, each with its own look or one unified look. Mosaik connects straight to each network
from your phone: no server in the middle reads your messages.

**Mosaik is in beta.** Download the APK from [Releases](https://github.com/kota-zo/Mosaik/releases)
(the newest *pre-release*), install it, and Mosaik offers the next versions itself
(Settings → About Mosaik).

- Android 10 or newer, 64-bit ARM phone.
- Mosaik is not made by Meta, WhatsApp, Instagram, Telegram, Discord or Snap. Networks don't
  support unofficial apps: in rare cases they may limit an account that uses one. Use a secondary
  account if yours matters a lot to you.
- Problems and ideas: Settings → Report a problem / Suggest an idea, or the
  [Mosaik Discord](https://discord.gg/Nzz67Vp6ZQ).
- Beta testers get a code for 7 days of Premium, free and without a card, on the Discord server.

Each APK's SHA-256 is given in its release notes.
